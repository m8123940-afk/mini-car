TURBO RIVALS 3D — ИСПРАВЛЕННЫЙ NODE.JS СЕРВЕР В корне репозитория сервера должны лежать server.js, package.json, admin.html и render.yaml. В Render оставь Root Directory пустым, если файлы лежат в корне репозитория. Переменные окружения Render: ADMIN_PASSWORD = новый уникальный длинный пароль админ-панели ALLOWED_ORIGINS = https://m8123940-afk.github.io Важно: - На ранее присланном скриншоте пароль администратора был виден. Обязательно замени его в Render на новый секрет и не отправляй его в чат/скриншотах. - В ALLOWED_ORIGINS нужен только origin, без /mini-car/ и без завершающего слеша. Обновлённый код дополнительно нормализует полный URL, но лучше указать правильно. - После изменения переменных выполни Manual Deploy / Deploy latest commit. - Проверь https://mini-car.onrender.com/health — должен вернуться JSON с "ok":true. - Клиент подключается к wss://mini-car.onrender.com. - Аккаунты сохраняются в data/accounts.json. Чтобы гарантировать хранение между переразвертываниями, используй persistent disk (например, Mount Path /var/data) и переменную DATA_DIR=/var/data, если тариф Render это поддерживает. - Перезапуск сервера может потребовать повторного входа: активные сессии в памяти.
